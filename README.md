# 派報系統

巷弄派報用的手機網頁 App：圈選區塊、自動規劃走遍所有巷弄的最短路線，並透過藍牙耳機語音導航。

網址：https://andy8879576.github.io/paibao/

## 功能
- 在地圖上圈選區塊，或輸入經緯度建立區塊，可命名、儲存、隱藏框線
- 自動下載區塊內的街道與門牌（開放街圖 OpenStreetMap）
- 規劃走遍所有巷弄的最短路線，死巷提示「右進左出」
- 語音導航：轉彎前預告與提醒，距離和頻率可在「設定」調整
- 偏離路線自動重新規劃，只排還沒派的巷子
- 進度顯示（橘色待派、綠色已派），隔天可接著派
- 標記拒收、沒信箱、有狗的住戶，下次經過時提醒
- 語音指令：暫停、繼續、重複、跳過這條、重新規劃、進度、標記有狗、我在○○巷○號
- GPS 跑掉時，可用門牌或在地圖上點選來修正位置

## iPhone 使用方式
1. 用 Safari 打開上面的網址，允許使用位置
2. 按分享鍵 → 加入主畫面
3. 要用語音指令，請到「設定 › 一般 › 鍵盤」打開「聽寫」
4. 使用時螢幕要保持開著，建議帶行動電源

資料（區塊、進度、標記）都存在手機的 Safari 裡。
